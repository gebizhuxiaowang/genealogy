# 五朝皇室近亲数据编纂状态

## 数据边界

本轮产品升级支持“皇帝—可考父母、配偶/后妃、子女、孙辈、继嗣与关键旁支继位”的完整近亲模型。这里的“可考”必须同时满足：人物或关系有明确史料来源；来源可定位到正史本纪、列传、世表、年表或可靠校勘材料；史料冲突时以 `certainty: disputed` 和说明保留差异。

不应将“史书未载”误写成“无子”或“无配偶”。对于后妃、早夭子女、庶出子女、追尊皇族、入继/兼祧和异文姓名，必须分别建人物、关系和来源记录。

## 编纂记录格式

每次扩充必须同时提交以下四类事实：

1. `persons`：姓名、异名/庙号、生卒或未知标识、人物来源。
2. `unions`：配偶或后妃关系、关系类型、来源与不确定性。
3. `parentChildRelations`：每条亲子、收养、继亲、继嗣关系及其来源。
4. `sources`：史料标题、卷/篇/页码或稳定链接、版本和差异说明。

首次全量编纂应以《旧唐书》《新唐书》《宋史》《元史》《明史》《清史稿》及其世表/后妃/宗室章节为主，交叉资料仅用于标注异文。完成一个朝代后，必须运行项目 schema、人物/关系来源引用、循环关系和项目包往返测试，才可以标记为“近亲数据已核验”。
