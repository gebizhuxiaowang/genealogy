# 唐宋元明清 五代皇室族谱数据集

## 概述

本数据集收录唐、宋、元、明、清五个朝代，从开国皇帝到末代皇帝的皇室家庭成员（配偶、子嗣）与主要成就。
每个朝代一个 JSON 文件：

| 文件 | 朝代 | 起止 |
|---|---|---|
| [tang.json](tang.json) | 唐（含武周） | 618–907 |
| [song.json](song.json) | 宋（北宋+南宋） | 960–1279 |
| [yuan.json](yuan.json) | 元（含大蒙古国追尊诸帝） | 1206–1368 |
| [ming.json](ming.json) | 明 | 1368–1644 |
| [qing.json](qing.json) | 清（含后金） | 1616–1912 |

## 来源与可信度标记规则

1. **正史**（最高可信）：《旧唐书》《新唐书》《资治通鉴》《宋史》《元史》《明史》《清史稿》等，标注具体篇目。
2. **杂史/笔记**（中等可信）：如《唐会要》《东京梦华录》《万历野获编》《清稗类钞》等，source 中注明，`disputed` 视情况标 true。
3. **野史/传说/民间故事**（如"狸猫换太子""乾隆为海宁陈家子""顺治出家"）：一律 `disputed: true`，并在 note 中说明"传说""野史""存疑"。
4. **史料缺失**：late 期皇帝后妃子女记载稀少时，在 note 中注明"史料记载较少"。

## 完整性说明

- 每位皇帝均收录，但后妃、子女仅收录**史料有明确记载的主要成员**（皇后、知名妃嫔、太子及知名皇子公主）。全部皇子皇女（如唐高祖 22 子、康熙 35 子）不逐一罗列，在 note 中说明总数。
- 血缘存疑、继嗣关系（如宋孝宗为太祖之后、明世宗以外藩入继）均在 `relationship_type` 与 `note` 中标注。
